What needle-ry1 Actually Executes

No hypothetical features. Every capability below is verified and integrated directly into the local runtime.

Safe Non-Destructive File Conversion

Converts documents, images, and audio locally using native CLI tools: LibreOffice, ImageMagick, and FFmpeg.

  • Original file is never deleted or overwritten
  • Safe collision naming: file (1).ext
  • Handles long file paths and spaces gracefully
Handler: convert_file(src, ext)

Universal Media Downloader

Directly powered by yt-dlp. Downloads video and audio into your system ~/Downloads directory.

  • Direct URL support: YouTube, X/Twitter, Vimeo
  • Natural title search: "download interstellar theme"
  • Real-time transfer progress streamed to HUD
Handler: download_media(url_or_query)

Air-Gapped Privacy & Zero Tracking

The 45M neural weights evaluate strictly on your CPU. No telemetry packets, analytics, or background requests are ever dispatched.

  • Operates completely offline with network disconnected
  • Zero cloud API keys, subscriptions, or login accounts
  • Permissive Apache 2.0 open-source license
Engine: libneedle.so / ry1 C-FFI

Honest Engineering Boundaries

We believe in total honesty about what a 45M edge model does and does not do.

1. Not a General Chatbot

With 45 million parameters, it has no general world knowledge. It will not write essays, generate poems, or answer historical trivia.

2. Single-Step Execution

It is a deterministic reflex layer. It handles one clear command at a time and does not run recursive autonomous loops.

3. Strict Schema Mapping

It maps language strictly into registered system tools (convert_file, download_media, search_media).
